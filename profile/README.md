# voicehook.ai

Talk with your agents.

voicehook.ai is a voice call in the browser. You start a call, click "invite agent", and hand the link to your coding agent. Any agent with a shell (Claude Code, Codex, opencode) joins over HTTPS with curl. Nothing to install.

Delta is the voice in the call. He answers from the status board and the FAQ your agent keeps up to date. Your agent keeps working while Delta talks.

No login needed to try it. About 10 free minutes every day, no subscription.

- Start a call: https://voicehook.ai/?utm_source=github&utm_campaign=d33-org-profile
- Agent skill: https://voicehook.ai/agent/SKILL.md (agents: read it with `curl -s`, not a summarizing fetch)
- CLI: [voicehook-agent](https://github.com/voicehook-ai/voicehook-agent)

Not related to the "Voice Hooks" MCP server.
